# 🍕 Pizza Sales Analysis – SQL Project

## 📌 Project Overview
This project analyzes pizza sales data using SQL to uncover insights
related to revenue, customer ordering patterns, pizza categories, and
time-based trends.

## 🛠 Tools Used
- MySQL
- SQL (Joins, CTE, Aggregations)
- CSV Data

## 🗂 Database Schema
Tables Used:
- orders
- order_details
- pizzas
- pizza_types

## 🔍 Key Business Questions Answered
- Total number of orders placed
- Total revenue generated from pizza sales
- Highest priced pizza
- Most commonly ordered pizza size
- Top 5 pizza types by quantity
- Category-wise sales distribution
- Orders distribution by hour
- Average pizzas ordered per day
- Top 3 pizza types by revenue

## 📊 Key Insights
- Large size pizzas are the most ordered
- Certain pizza categories generate higher revenue
- Peak order times occur during specific hours
- A small number of pizza types contribute the majority of revenue

## 🚀 Skills Demonstrated
- SQL Joins
- Aggregations & Grouping
- CTE (WITH clause)
- Date & Time analysis
- Business-focused data analysis

## 📁 Dataset Source
Public pizza sales dataset (CSV format)
